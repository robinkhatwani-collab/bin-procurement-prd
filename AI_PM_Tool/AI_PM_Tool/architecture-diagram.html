Key Design Decisions

🔗 Two Entry Points — One System

  • Browser chatboard → Webhook → Agent 2 (simple HTTP)
  • Claude Desktop → MCP SSE → MCP Workflow (protocol-native)
  • Same HTML data source — different reasoning layer
  • Browsers can't be MCP clients — webhook bridges the gap

🧠 Agent 2 — Dynamic Project Routing

  • Reads registry.json to discover all projects
  • Keyword matches user question to project slug
  • Fetches specific status-tracker.html or all-project summary
  • New project = update registry only, no workflow change

🤝 Multi Agent — Contract Analysis

  • PDF extracted once — stored in session memory
  • IF node skips re-extraction on follow-up questions
  • Orchestrator routes by intent: process / risk / off-topic
  • Each sub-agent queries one data source only

🔌 MCP Architecture

  • n8n MCP Server exposes 3 tools to Claude Desktop
  • No LLM inside n8n — Claude Desktop is the brain
  • Tools return raw HTML; Claude reasons over it
  • Tool descriptions are the routing signal for Claude
